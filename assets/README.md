Optional invitation assets

- invitation-photo.jpg: wedding photograph (also used behind the hero).
- music.mp3: add your own audio and set CONFIG.musicEnabled to true in script.js.
- background.jpg, envelope-texture.jpg, seal.png are not required: the background,
  paper texture and embossed wax seal are drawn in CSS and work offline.

You may replace invitation-photo.jpg with your own photograph using the same name.

- wax-heart.png: optional final seal; set CONFIG.waxHeartPath after adding the image.
- stamp.mp3: optional quiet stamp sound; set CONFIG.stampSoundEnabled to true after adding it.
The final screen uses an inline SVG wax heart when no custom seal is configured.
